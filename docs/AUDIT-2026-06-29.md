# Atelier Bismuth — Store Launch Audit

**Prepared for:** David (operator) · **Date:** 2026-06-29 · **Store:** yev0ep-p9.myshopify.com (Basic plan, USD)

---

## 1. Executive Summary

**Verdict: NOT ready to publish. The store is close on craft, but several hard launch blockers remain — most critically, the storefront the public sees today is still the stock "Balance" theme, not the bespoke Atelier Bismuth build.**

- **The bespoke theme is unpublished.** Visitors currently render stock Shopify "Balance." Publishing the Atelier Bismuth theme is the single biggest unblock — but it must happen *after* the fixes below, not before.
- **Dimensions never show on the storefront.** Every product stores its real dimensions, but the theme reads the wrong metafield keys, so the PDP "Dimensions" accordion and product cards display no measurements at all — a serious credibility gap for furniture priced up to ~$19,900.
- **Legal/trust gaps block a clean launch.** No Refund, Shipping, or Terms policies; the one Privacy policy is an unedited template full of `{{ placeholders }}`. The store is still literally named "My Store," which leaks into page titles, the footer copyright, and policies.
- **Etsy residue is still live.** "Just message me," baked-in freight dollar amounts ("Price includes 500 freight"), and a typo ("in included") appear in ~20 active descriptions. No image has alt text.
- **The good news:** pricing is solid (729 active variants match Etsy exactly, zero $0.00 prices), taxonomy and collections are clean, the homepage design faithfully matches the reference build, and SEO/accessibility fundamentals are strong. The blockers are configuration and data-contract issues, not a broken build.

## 2. Launch Blockers (Critical / High)

### A. Theme & rendering

**A1. Bespoke theme is UNPUBLISHED — public sees stock "Balance"** · *Critical* · **Auto-fixable (publish action)**
- **Location:** Online Store → Themes. `Balance` = MAIN; `Atelier-Bismuth` (gid 153359089843) = UNPUBLISHED.
- **Why it matters:** None of the work in this audit is visible to customers until this theme is published. Today the storefront is a generic free theme.
- **Fix:** Publish the Atelier-Bismuth theme **after** the fixes below pass QA. Keep Balance/Canyon as unpublished backups. *(Publishing is a one-click admin action — David should do it as the final step.)*

**A2. Product dimensions never render** · *Critical* · **Claude can auto-fix (code)**
- **Location:** `snippets/dimensions.liquid:17-61` (used by `main-product.liquid:50,108`, `product-card.liquid:45`, `cart-drawer.liquid:24`, `main-cart.liquid:21`).
- **Why it matters:** Every active product has a populated `specs.dimensions` string (e.g. `50″ L × 24″ D × 14″ H`), but the snippet only reads `specs.width/depth/height/diameter` — keys that **do not exist** on any product. Result: product cards show no size, and the PDP accordion literally labeled "Dimensions" renders only Materials + Finish with no measurements. For luxury stone furniture, missing dimensions is a conversion killer.
- **Fix:** Add a branch to `dimensions.liquid` to render `s.dimensions` directly (table row + inline card string), keeping the per-axis logic as fallback. Re-verify the accordion is non-empty.

**A3. The correct specs section is orphaned** · *High* · **Claude can auto-fix (code)**
- **Location:** `sections/atelier-specs.liquid` (reads the populated `specs.dimensions` correctly) is referenced by **no** template; `templates/product.json` order is only `["main","related"]`.
- **Why it matters:** The one component built to display real dimensions is dead code, while the placed path (A2) is broken. Don't ship both.
- **Fix:** Either wire `atelier-specs` into `templates/product.json`, **or** fix A2 and retire the orphan. Pick one source of truth — not both.

**A4. Brand fonts will be (are being) overridden by `assistant_n4` default** · *High* · **Claude can auto-fix (code)**
- **Location:** `config/settings_schema.json:38-39` — both `heading_font` and `body_font` default to `assistant_n4` (off-brand sans "Assistant").
- **Why it matters:** Shopify `font_picker` settings always resolve to their default even when absent from `settings_data.json`, so `layout/theme.liquid:41-48` already emits `--font-display: Assistant…`, overriding the Cormorant Garamond / Jost defaults in `base.css`. (Note: this audit could not screenshot the rendered storefront because the theme is unpublished, but the Liquid semantics make the override active, not merely latent.)
- **Fix:** Change both defaults to the brand fonts (`cormorant_garamond_n4` for headings, `jost_n4` for body — confirm exact Shopify library handles), **or** remove the pickers from the schema and rely on `base.css` + the Google Fonts link.

### B. Configuration & legal (David / Shopify admin)

**B1. Store still named "My Store"** · *High* · **David (admin) — Claude can guide**
- **Location:** Settings → Store details → Store name (`shop.name = "My Store"`).
- **Why it matters:** Leaks into browser tab titles (`… – My Store`), `og:site_name`, footer copyright ("© 2026 My Store. All editions reserved."), JSON-LD brand, and the privacy-policy `{{ shop_name }}` token.
- **Fix:** Set Store name to **"Atelier Bismuth"** in Settings → Store details.

**B2. Refund, Shipping, and Terms of Service policies are all missing** · *High* · **David (admin)**
- **Location:** Settings → Policies (`shop.shopPolicies`). Only a PRIVACY_POLICY exists — and it's the unedited Shopify default, still containing `{{ shop_name }}`, `{{ phone }}`, `{{ email }}`, `{{ address }}`, `{{ last_updated }}`.
- **Why it matters:** For heavy stone freight with items up to ~$19,900, missing returns/shipping/damage terms is both a legal exposure and a trust signal.
- **Fix:** Add Refund/Return, Shipping, and Terms policies. Write a real freight policy (lead times, freight, damage claims, custom-order non-returnability) rather than the generic template. Fill in the Privacy template placeholders (auto-resolves once B1 is done).

**B3. Footer "Shop" and "Atelier" columns are empty** · *High* · **David (admin) — create menus**
- **Location:** `sections/footer-group.json:12-13` reference link lists `footer-shop` / `footer-atelier`; `footer.liquid:47` references `footer-legal`. None exist in the store (live menus are only `main-menu`, `footer`, `customer-account-main-menu`).
- **Why it matters:** Both footer columns collapse to a single fallback "All pieces" link on every page — looks broken/unfinished.
- **Fix:** Create three menus in Online Store → Navigation:
  - **footer-shop:** Furniture `/collections/furniture`, Objects & Decor `/collections/objects-decor`, New Arrivals `/collections/new-arrivals`, Best Sellers `/collections/best-sellers`, Collection `/collections/all`
  - **footer-atelier:** Our Story `/pages/about`, Custom orders, Trade program, Contact `/pages/contact`
  - **footer-legal** (optional): Privacy, Returns, Shipping

**B4. 27 sellable products (143 variants) are status UNLISTED** · *High* · **David (admin decision)**
- **Location:** Live catalog; e.g. `live-edge-wood-floating-shelf-shou-sugi-ban-charred-wood` (76 variants), `raw-travertine-jewelry-display-stand-handmade-stone-stand` (8), `chiseled-travertine-jewelry-display-stand-handcrafted-stone-stand` (8), and others.
- **Why it matters:** These are priced, in collections, and otherwise launch-quality, but UNLISTED = hidden from the storefront. If they should be sellable at launch, they're invisible; if they should be hidden, confirm intentionally.
- **Fix:** David to decide per product: set to ACTIVE for launch, or confirm they're intentionally held back.

### C. Content & catalog data

**C1. Zero alt text across all 70 active products** · *High* · **Claude can auto-fix (bulk script)**
- **Location:** Live Admin API — every `images[].altText` is `""` or null. Image URLs are raw Etsy exports (`il_fullxfull.NNNN_xxxx.jpg`).
- **Why it matters:** Accessibility failure, lost image SEO, and a polish gap.
- **Fix:** Bulk-seed alt text from `title + material + view` (e.g. "Travertine pedestal column, honed solid stone, front view") via `productUpdate`, then hand-refine hero images.

**C2. "Message me / Just message me" Etsy artifacts in 10 active descriptions** · *High* · **Claude can auto-fix (data)**
- **Location:** Live descriptions — chiseled shelf family (8), `handcrafted-travertine-waterfall-console-table-natural-stone-desk`, `travertine-bench-wabi-sabi-stone-entryway-bench-with-steel-legs`.
- **Why it matters:** There is no DM system on the storefront; the language is broken and off-brand.
- **Fix:** Replace with "Contact the atelier" (link to `/pages/contact`) or "Bespoke sizing available on request." Standardize across the shelf family.

**C3. Freight dollar amounts baked into 9 descriptions** · *High* · **Claude can auto-fix (data)**
- **Location:** Live descriptions — e.g. `travertine-pedestal-column-sculpture-stand-…` and `travertine-fountain-column-…` ("Price includes 500 freight shipping in the USA"); 6 pedestals ("Free Fedex shipping included in pricing"); `chiseled-travertine-fireplace-hearth-…` ("Free shipping **in included** in the price" — typo confirmed live).
- **Why it matters:** Raw "500 freight" (no currency) reads as a data leak; promises and a typo undercut the luxury tone.
- **Fix:** Remove embedded figures; express shipping once via the Shipping policy/rates. If "free US freight" is a selling point, phrase as "Complimentary US freight shipping" (no raw number). Fix the hearth typo.

### D. Pricing

**D1. 48″-wide row dips below both neighbors on 3 chiseled shelves** · *High* · **Claude can auto-fix (data)**
- **Location:** `chiseled-travertine-floating-shelf-…-invisible-shelf`, `chiseled-frosted-travertine-floating-shelf-…-rare`, `chiseled-travertine-mantle-shelf-…-mantlepiece`. Variants Width=48 at Depth 6/8/10.
- **Why it matters:** Etsy skips W48 entirely (jumps 46→50), so W48 is a Shopify-only interpolated rung — and it was extrapolated *downward*, landing ~$130 **below** W46 and ~$230 below W50. A wider shelf costing less than a narrower one is an obvious, trust-eroding pricing error. (The Chiseled Silver shelf interpolated W48 correctly upward, proving the fix.)
- **Fix:** Set Width=48 to the W46↔W50 midpoint: **D6=$1749, D8=$1849, D10=$1949** (keep D4 as-is). Mirror the working Silver-shelf formula.

## 4. Polish & Nice-to-haves (Low / Info)

- **No `compare_at_price` anywhere** (all 1,215 variants null) — there is no visible sale on the storefront. The Etsy "15% off" is baked into the displayed price as the regular price. This is a *business decision*, not a bug: if David wants a visible strike-through sale, compare-at values must be set.
- **Dead `per_page` setting** in the theme config (unused).
- **Recommendations path never fires** — `related-products.liquid` uses the `recommendations` object but there's no client-side `intent=related` fetch in `theme.js`. Related products may render empty until wired (verify post-publish).
- **Global Organization / Breadcrumb JSON-LD absent** (Product JSON-LD is present and correct). Minor SEO upside.
- **A11y contrast nits:** the single "muted" tone and the footer-bottom tone fall below WCAG AA; everything else passes comfortably (ink 15.4:1, ink-soft 8.3:1, accent 5.8:1, footer links 10.5:1).
- **Admin product counts are inflated by unpublished items** — cosmetic, resolves once B4 is decided.
